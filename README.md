## ✨ Features

- 🔎 **Live search** with `Ctrl+K` keyboard shortcut — filter by name, language, license, or category
- 🏷️ **Category filters** — 11 categories, one click to narrow down
- 🎴 **Glass-morphism cards** — frosted glass panels with radial hover glow
- ✨ **Animated particle background** — subtle floating network behind the content
- 📜 **Scroll-triggered animations** — sections fade in as you browse
- 📱 **Fully responsive** — looks great from phones to ultrawide monitors
- 🔍 **SEO optimized** — Open Graph, Twitter Cards, JSON-LD structured data

## 🙌 Contributing

Got a tool to add? Found a broken link?

1. **[Fork](https://github.com/JamesCowx/OpenSauce/fork)** the repo
2. Add your tool to the `tools` array inside `index.html`:

```js
{ name:"Tool Name", icon:"🛠️", desc:"What it does.", url:"https://tool.url", tags:["MIT","Python","Type"], category:"Development" }
```

3. Open a **pull request**

> Please only submit tools that are genuinely open-source and actively maintained.
