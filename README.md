<h2>⚙️ &nbsp;How It Works</h2>

```
index.html        ←  the whole site (HTML + CSS + JS + data)
│
├── <style>       ←  400 lines of hand-crafted CSS
│   ├── CSS custom properties (theme tokens)
│   ├── Glass morphism + backdrop-filter
│   ├── CSS animations & keyframes
│   └── Media queries for responsiveness
│
├── <canvas>      ←  animated particle background
│   └── 70 particles, distance-based connections
│
└── <script>      ←  200 lines of vanilla JS
    ├── tools[] data (85+ entries)
    ├── Search + filter logic
    ├── DOM rendering (grouped by category)
    └── IntersectionObserver for scroll animation
```

One file. No build step. Just open and go.

<h2>🙌 &nbsp;Contribute</h2>

Got a tool that should be here? Spotted something wrong?

```bash
# 1. Fork → Clone → Edit
git clone https://github.com/YOUR_USERNAME/OpenSauce.git
code OpenSauce/index.html

# 2. Add your tool to the tools[] array:
```

```js
{
  name: "Your Tool",
  icon: "🛠️",
  desc: "One-line description of what it does.",
  url: "https://github.com/author/tool",
  tags: ["License", "Language", "Type"],
  category: "Development"  // pick from 11 categories
}
```

```bash
# 3. Push → PR
git commit -m "Add Your Tool to the collection"
git push
# Then open a pull request on GitHub
```

> **Guidelines:** genuinely open-source, actively maintained, useful to others. No spam, no abandoned projects, no proprietary bait-and-switch.
